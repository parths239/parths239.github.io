Laguna - a twitter like web app

GithubVisit Site

I have created a full stack web app called Laguna, where people can create accounts, make posts, and view others’ posts! I plan to add features like adding friends and ways to make connections!

  1. Launched a Django-based twitter like web application, utilizing Python, Django, JavaScript, HTML, and CSS to create a responsive and dynamic user experience.
  2. Implemented backend functionality using Django framework, including user authentication, profile management, and content administration, with deployment on Linode and AWS for scalable and secure hosting.
  3. Configured PostgreSQL as the database, ensuring robust data handling, smooth performance, and optimized query execution for a live production environment.
